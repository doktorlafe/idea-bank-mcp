Get started

① claude.ai, no install: Settings → Connectors → Add custom connector, then paste: 
https://mcp.laferrari.eu/mcp
② Claude Code 
claude mcp add idea-bank -- npx -y idea-bank
③ Claude Desktop / any MCP client 
{ "mcpServers": { "idea-bank": { "command": "npx", "args": ["-y", "idea-bank"] } } }

The hosted endpoint only recommends ideas and is rate-limited. The local version also analyses your own portfolio and lets you keep a private idea bank.
